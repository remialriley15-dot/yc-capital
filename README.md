# YC Capital

YC Capital is an XAUUSD trading-signal dashboard prototype.

## V1
- BUY / SELL / WAIT signal states
- Entry, stop loss, TP1 and TP2
- Risk/reward-oriented signal layout
- Signal reasoning/status
- MT5 bridge placeholder
- Responsive mobile dashboard

## Important
The current dashboard uses placeholder/demo data. It does **not** generate live financial advice or execute trades. A market-data provider and validated signal engine must be connected before live use. Test any strategy on an MT5 demo account first.

## Roadmap
1. Connect live XAUUSD market data
2. Implement and backtest signal rules
3. Add persistent signal history
4. Build MT5 EA/bridge
5. Add authentication and deployment
